### Running these tutorials

In addition to the dependencies in requirements.txt, you'll also need to be able to open and run ipynb's in order to play around with these tutorials. 

First, see "How to install" in the README.md file, and follow the instructions there to create a custom environment and install the main dependencies. Afterwards, run this in the terminal:

```
pip install notebook
```

and then open it:

```
jupyter notebook
```
